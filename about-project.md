- **Modules**: Each feature (e.g., `blogs`, `services`, `users`) is self-contained.
- **Separation of Concerns**: Each module follows a strict pattern:
    - `.dto.ts`: Data Transfer Objects for type safety.
    - `.mapper.ts`: Transforming data between layers.

    - `.repository.ts`: Data access layer.
    - `.service.ts`: Business logic layer.
    - `.server.ts`: Server-side specific logic.
    - `__tests__`: Dedicated unit tests for each module.
